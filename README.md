# 🧙‍♂️ קוסמי הרשת – משחק עולם פתוח ללימוד כתובות IP

משחק תלת-ממדי בדפדפן, בסגנון עולם קסמים פתוח (בהשראת "הוגוורטס לגאסי"), שבו לומדים **כתובות IP, DHCP והגדרות רשת** בהתאם ל-CCNA ולתוכנית רשתות תקשוב י״א–י״ב.

## הרצה
```bash
npm install
npm run build        # בונה את dist/game.js (מצורף כבר בריפו)
npm start            # שרת סטטי על http://localhost:8080
```
אפשר גם לפתוח את `index.html` ישירות (הקוד ארוז בקובץ אחד).

## העולם
* אי ענק (~4 ק״מ) עם הרים, אגמים, יערות, ביצה, מערה, כפרים וטירה — נוצר פרוצדורלית, עם מחזור יום/לילה.
* דמויות NPC שמסתובבות ומשוחחות, חד-קרנים, היפוגריפים, ינשופים, דרקון, עוף חול וסניץ׳ זהוב.
* **מטאטאים** (6 סוגים שנפתחים עם ההתקדמות), **שרביט ו-8 לחשים** (לומוס, ויינגרדיום, אינסנדיו, סטופפיי, פרוטגו, אקספלימיוס, אקסיו, פטרונוס), **שיקויים** (איסוף מרכיבים, בישול בקלחות), תיבות אוצר ומרוץ טבעות.

## שבעה אזורי לימוד
כל אזור: הסבר בשלבים + סימולציות/אנימציות אינטראקטיביות + שאלות הבנה + שאלות סיכום + משחקון שקשור ישירות לחומר.

| # | אזור | נושא | משחקון |
|---|------|------|--------|
| 1 | מגדל הכתובות | מבנה כתובת IP, בינארי↔עשרוני, IP מול MAC, IPv4/IPv6 | רונות בינאריות |
| 2 | אי הרשתות | חלק רשת/מארח, מסיכה, כתובת רשת ו-Broadcast, מחלקות, תקשורת בין רשתות | דואר ינשופים |
| 3 | יער השערים | כתובות פרטיות/ציבוריות, NAT, כתובות מיוחדות | שומרי השער |
| 4 | ביצת הניצוצות | סטטית מול דינמית, התנגשויות, תכנון כתובות | זיכרון הקסם |
| 5 | מערת הדרקון | DHCP, DORA, מאגר/החרגות/Lease, APIPA, Relay, ipconfig | שומר מאגר הכתובות |
| 6 | סדנת הקסמים | הגדרת IP סטטי ו-DHCP בווינדוס ו-Packet Tracer, ipconfig/ping | תיקון הקסם הרשתי |
| 7 | מגדל הראוטר | CLI של סיסקו: ממשק, excluded-address, ip dhcp pool, show | ספר הפקודות (סימולטור IOS) |

**שלוש רמות קושי** (מתחיל ×1, קוסם ×1.5, מאסטר ×2) משפיעות על סוג השאלות, רמזים, זמנים, מורכבות המשחקונים והכפלת הניקוד.

## שליטה
`WASD` תנועה · עכבר מבט · קליק לחש · `1-8` בחירת לחש · `B` מטאטא · `E` אינטראקציה · `P` שיקויים · `M` מפה · `J` יומן · `Esc` תפריט. תומך גם במגע.

## מבנה הקוד
* `src/world/` – שטח (Quadtree LOD), שמיים, מים, צמחייה, מבנים, דמויות ויצורים.
* `src/learn/` – מנוע הלימוד, סימולציות, מסוף Windows וסימולטור Cisco IOS, תוכן 7 האזורים והמשחקונים.
* `build.mjs` – בנייה עם esbuild (Three.js ארוז מקומית, בלי תלות ברשת).
